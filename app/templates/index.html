Know which orders will arrive late, before they do.

ShopPulse-AI predicts late delivery for an e-commerce order using a Random Forest and a Keras neural network, and reads customer review sentiment with an NLP model.

Machine Learning

Deep Learning

NLP Sentiment

TF-IDF + Logistic Regression on review text, served from POST /sentiment.

    ShopPulse-AI

    A university data science project that predicts whether an e-commerce order will be delivered late and analyzes customer review sentiment.

    Objective

    Give customers and evaluators an easy interface to the trained models.

    Technology

    Backend: Python, FastAPI. Models: Scikit-learn (Random Forest, TF-IDF + Logistic Regression), TensorFlow/Keras. Frontend: HTML, CSS, vanilla JavaScript, Jinja2.
